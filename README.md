# Pokémon Search 🐾

A simple website that lets you search for Pokémon by name and see their info. This was the first project where I worked with an external API.

**Live site:** https://pokemonnnnnn.vercel.app/

**Repo:** https://github.com/dweep-js/pokemon

## Features

- Search for any Pokémon by name
- Fetches and displays live data from the [PokéAPI](https://pokeapi.co/)
- Simple, clean single-page interface

## Tech Stack

- Vanilla JavaScript, HTML, and CSS
- [PokéAPI](https://pokeapi.co/) for Pokémon data
- Deployed on Vercel

## Usage

1. Open the site
2. Type in a Pokémon's name
3. Hit search to see its details

## Local Development

```bash
git clone https://github.com/dweep-js/pokemon.git
cd pokemon
```

Then open `index.html` in your browser — no build step required.
